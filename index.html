資料說明（點擊展開）

利率及交易量來源：紐約聯準銀行 Markets Data API。

聯準會準備金來源：FRED WRESBAL，透過 GitHub Actions 下載至 reserves.csv，網頁讀取已發布的資料檔案。

商業銀行總資產來源：FRED TLAACBW027NBOG，透過 GitHub Actions 更新 bank_assets.csv。原始單位為十億美元；準備金 WRESBAL 原始單位為百萬美元，計算占比時先統一單位。兩種占比均採三組資料最新共同觀測日期；每週平均與週三當日的統計口徑不同。

週三準備金來源：FRED WRBWFRBL（百萬美元），透過 reserves_wednesday.csv 讀取。

SOFR − EFFR 以相同有效日期相減，單位 bp。第 99 百分位數並非最高成交利率。

ON-RRP：FRED RRPONTSYD（十億美元）；TGA：FRED WTREGEN（百萬美元，每週平均）。透過 GitHub CSV 讀取，顯示億美元及前期變動。前期為前一筆有效觀測值。

利差燈號：≥1 bp 黃燈，低於 1 bp 綠燈；最新利率日期不同或資料缺失為灰燈。黃燈僅為門檻提示。

交易量與準備金以美元表示。變化為與前一筆有效資料比較。

黃金、白銀及 VIX 尚未接入報價來源，不使用模擬行情。
